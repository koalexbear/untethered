## Claude Code

- A SessionStart hook (`.claude/settings.json`) prints the work board when a session
  starts. Claim your task before you edit anything, and name yourself with `--by` (your
  session's short name) so other sessions can tell who you are.
- Sessions started from another session: the parent coordinates and merges; you work on
  your own branch and report back. Keep your claim's notes current so the parent can see
  progress without asking.
